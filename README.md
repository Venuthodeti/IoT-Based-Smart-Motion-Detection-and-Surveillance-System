# 📷 IoT-Based Smart Motion Detection and Surveillance System

## 📌 Project Overview

This project is an IoT-based smart surveillance system designed to detect human movement and automatically capture images using an ESP32-CAM module.

The system uses a PIR (Passive Infrared) motion sensor to detect movement in its surrounding area. Whenever motion is detected, the ESP32-CAM captures images, which are transmitted through Wi-Fi using the NodeMCU (ESP8266) and uploaded to a website for remote monitoring.

The main goal is to develop a low-cost, smart, and efficient surveillance solution that allows users to monitor activities remotely.

## 🎯 Objectives

- Detect movement using a PIR motion sensor.
- Automatically capture images when motion is detected.
- Transfer captured images through Wi-Fi.
- Upload captured images to a web-based dashboard.
- Enable remote monitoring through a website.

## 🔄 Working Principle

1. The PIR sensor continuously monitors the surrounding area.
2. When movement is detected, it sends a signal to the controller.
3. The ESP32-CAM is triggered to capture an image.
4. The captured image is transferred through the Wi-Fi communication setup.
5. NodeMCU helps establish wireless communication for uploading the images.
6. The images are displayed on a website dashboard, allowing users to monitor detected activities.
